# EraFall: Age of Onslaught

Godot 4 portrait Android game: grow your tribe through gates, automatically throw spears, battle a dire wolf and war chief, and advance through eras.

Project source, UI button sprites, and signed Android build workflow are being added in the initial project milestone.

- Android application ID: `com.dabsky.erafall`
- Release signing alias: `erafall`
- Repository secrets: `ERAFALL_KEYSTORE_BASE64`, `ERAFALL_STORE_PASSWORD`, `ERAFALL_KEY_ALIAS`, `ERAFALL_KEY_PASSWORD`

Never commit the keystore or its passwords.
